\chapter{Additional Test Cases}\label{app:tests}

This appendix lists the supplementary test cases TC11--TC30, which complement the ten principal cases of \cref{tab:eval-tc} in \cref{ch:eval}. Together they cover every functional and non-functional requirement that is in scope (FR01--FR18, NFR01--NFR09). Columns are as in \cref{tab:eval-tc}; all measured values are from the final versions of the components.
